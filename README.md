# Автосервис — система учёта заказов
 
Автор: Алейникова А. О., группа: О-24-ИСП-1-СПО.

Клиент-серверная информационная система для автоматизации работы автосервиса (администратор, мастер, механик, клиент и сервис Email/SMS-уведомлений): сервер Web API управляет базой заказов на ремонт, а настольное приложение WinForms позволяет просматривать, оформлять и удалять заказы.

## Состав решения

| Проект | Назначение |
|--------|------------|
| AutoServiceApi | Сервис Web API на ASP.NET Core |
| WorkOrdersDesk | Клиентское приложение мастера и администратора на WinForms |

## Требования

- .NET 8 SDK или новее (для сервиса Web API) и .NET Framework 4.8 (для клиента WinForms)
- Visual Studio 2022 с рабочими нагрузками «Разработка классических приложений .NET» и «ASP.NET и разработка веб-приложений»

## Как запустить

1. Откройте файл решения (`.sln`) в Visual Studio.
2. Выберите для проекта `AutoServiceApi` профиль запуска **http**.
3. В свойствах решения включите запуск нескольких проектов (`AutoServiceApi` — первым, `WorkOrdersDesk` — вторым).
4. Нажмите **F5**. Сервис запустится по адресу `http://localhost:5291`, интерактивная документация Swagger доступна по адресу `http://localhost:5291/swagger`.

## Адреса API

| Метод | Адрес | Описание |
|-------|-------|----------|
| GET | `/api/workorders` | Получить список всех заказов |
| GET | `/api/workorders/{id}` | Получить заказ по номеру |
| POST | `/api/workorders` | Создать новый заказ |
| DELETE | `/api/workorders/{id}` | Удалить заказ по номеру |

## Справка для пользователя

Руководство пользователя находится в файле `WorkOrdersDesk/Help/index.html` и открывается прямо из интерфейса программы через меню **«Справка → Руководство пользователя»**.
